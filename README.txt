Publish free with GitHub Pages:
1. Create a new public GitHub repository, e.g. ankur-portfolio.
2. Upload index.html (and this README).
3. Open repository Settings → Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select main and / (root), then Save.
6. Wait for GitHub Pages to publish. Your URL will look like:
   https://ankur-006.github.io/ankur-portfolio/

You can also import the folder/repository into Vercel.

Before publishing:
- Add your real email address and LinkedIn profile URL.
- Review project descriptions and update any project status/details.
- Add a project/demo link for Smart Campus Management if/when available.
